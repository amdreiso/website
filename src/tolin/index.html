Tolin

Tolin is a scripting language for GameMaker.

Tolin was made upon the need to modify the project's code without having to recompile the entire thing.

I created a tolin scripting language before for learning purposes, it was a stack based programming language, a video series by tsoding sparked my interest, where they created 'Porth'.

Getting Started

To get started with tolin, here's an example on how to initialize it.

state = tolin_state(); tolin_add_code(state, "print(\"Hello, world\")"); tolin_run(state);
